나라장터 API 정리

조달청 공공데이터 · 실제로 써보고 확인한 것만 적었습니다

세 가지가 서로 다른 서비스입니다. 각각 따로 활용신청을 해야 하고, 신청은 자동 승인됩니다. 개발계정은 하루 1,000회이고 서비스별로 따로 셉니다.

공통

serviceKey발급받은 키. Decoding 키를 쓰고, 쿼리에 넣을 땐 그대로 붙입니다.
typejson. 안 주면 XML이 옵니다.
pageNo / numOfRows1부터. numOfRows는 300까지 받아 봤습니다.
inqryDiv1 = 공고일 기준 조회. 이게 기본입니다.
inqryBgnDt
inqryEndDt		yyyyMMddHHmm (예 202609010000)

함정 셋

  • 조회 기간이 1개월을 넘으면 실패합니다. resultCode 07 · 입력범위값 초과 에러가 떨어집니다. 30일씩 잘라서 동시에 던지세요.
  • 오퍼레이션 이름이 PPSSrch로 끝나야 기관명·공고명 필터가 먹습니다. 그냥 getBidPblancListInfo…는 필터를 조용히 무시하고 전체를 돌려줍니다 — 오류도 안 납니다.
  • 응답 껍데기가 두 가지입니다. 정상일 땐 response.body.items, 오류일 땐 nkoneps.com.response.ResponseError.header. 둘 다 받아내야 합니다.
CORS가 열려 있습니다. 브라우저에서 바로 fetch할 수 있고, 첨부파일 내려받기도 됩니다. 서버가 필요 없습니다. 이게 이 도구가 단일 HTML로 돌아가는 이유입니다.

② 낙찰정보서비스 — 누가 얼마에 따냈는지

https://apis.data.go.kr/1230000/as/ScsbidInfoService/…

낙찰 결과와 투찰 내역을 줍니다. 초안 생성에는 안 쓰지만 「비슷한 사업이 얼마에 낙찰됐나」를 보여 주려면 필요합니다. 추정가격 대비 낙찰률을 참고치로 붙이면 시연이 좋아집니다.

③ 계약정보서비스 — 체결된 계약

https://apis.data.go.kr/1230000/ao/CntrctInfoService/…

계약 체결 내역입니다. 역시 초안 생성에는 안 씁니다.

개인정보에 주의하세요. 낙찰·계약 쪽 응답에는 대표자명·전화번호·사업자번호·주소·담당자명이 들어 있습니다. 받는 즉시 그 필드는 버리고, 화면에도 띄우지 마세요.

첨부파일 다루기

  • ntceSpecDocUrl{n}을 그대로 fetch하면 바이너리가 옵니다. 인증 없이 됩니다.
  • 확장자는 .hwp .hwpx .pdf가 섞여 있습니다. .hwpx가 가장 다루기 쉽습니다 — ZIP이라 Contents/section0.xml의 <hp:t>만 긁으면 본문이 나옵니다.
  • .hwp는 OLE2 + zlib입니다. 브라우저에서 하려면 FileHeader 37번째 바이트로 압축 여부를 보고, DecompressionStream('deflate-raw')으로 풀고, 태그 67(문단 텍스트)을 UTF-16LE로 읽습니다. 파이썬이면 훨씬 간단합니다.
  • 파일명에 과업지시서 제안요청서 과업내용서가 들어간 것만 고르면 됩니다.

세분류로 좁힐 때

같은 유형 공고를 찾으려면 8자리 세분류(pubPrcrmntClsfcNo)가 가장 정확합니다. 다만—

전시 장치 72154099 하나에 잘 모여 있어 세분류만으로 좁혀집니다.
행사 운영 기타사업지원서비스로 흩어져 있어 세분류만으로는 안 됩니다. 공고명 유사도를 같이 써야 합니다.

지역 필드(rgnLmtBidLocplcJdgmBssNm, jntcontrctDutyRgnNm1~3)는 개최지가 아니라 입찰 참가 제한 지역입니다. 대부분 비어 있습니다. 개최지로 쓰면 안 됩니다.

키 관리

  • 개발계정 하루 1,000회. 한 번 돌릴 때 용역·물품·공사 × 20창 = 60회가 나갑니다. 개발하면서 열 번만 돌려도 600회입니다.
  • 키를 두 개 준비해 번갈아 쓰세요. 계정을 하나 더 만들면 됩니다.
  • 첨부파일 내려받기는 API 호출 수에 안 들어갑니다.
  • 운영계정은 심사가 있어 며칠 걸립니다. 필요하면 미리 신청하세요.
