## 들어 있지 않은 것 (의도적)

해커톤 규칙상 **사전에 설계·개발한 사실이 확인되면 실격**입니다. 그래서 빼뒀습니다.

- 생성기 코드 (HTML·파이썬)
- 항목 사전 — 어떤 조항을 어떤 정규식으로 잡을지
- 기본 문안 — 항목별 미리 써둔 본문
- 구조 설계서 — 화면 흐름, 데이터 모델

이 넷은 **현장에서 만드는 것이 과제 본체**입니다. 여기 있는 건
공개 API 문서, 공개 공고문, 공개 법령, 라이브러리 사용법, 설치 파일,
그리고 통신이 살아 있는지 확인하는 점검 도구뿐입니다.

## 키는 여기 없습니다

공개 저장소라 조달청 serviceKey 와 Gemini 키는 올리지 않았습니다.
`.gitignore` 에 걸어 뒀습니다. **절대 커밋하지 마세요** — 올라가면
커밋을 지워도 키는 이미 노출된 것으로 취급해야 하고, 두 계정 모두 내 이름으로 발급된 것입니다.
현장에서는 점검 HTML 입력칸에 직접 붙여 쓰고, 끝나면 둘 다 재발급하세요.

## 발췌 JSON 안의 이름

`03_자료/발췌/` 의 두 JSON은 **실명·직통번호·메일을 ○○○ 로 바꿔** 올렸습니다.
원본은 공개 공고문이지만, 거기서 뽑은 동료 19명의 이름과 번호를 한 파일에 모아
공개 저장소에 두는 건 공고문에 흩어져 있는 것과 다른 일입니다.
`03_자료/원본_과업지시서/` 의 .hwp 는 나라장터에 공개된 문서 그대로 두었습니다.

`04_지침_법령/` 의 수의계약 업무처리지침은 경과원 내부 문서입니다.
공개 저장소에 두는 게 괜찮은지는 한 번 확인해 보세요.
