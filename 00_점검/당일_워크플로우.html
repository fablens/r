2026 GBSA AI 해커톤 · 10월 2일 수원컨벤션센터 · 과업지시서 초안 생성기

규칙이 먼저입니다. 「사전에 설계·개발한 사실이 확인될 경우 실격」. 지급 노트북·지급 계정에서 당일 작성해야 합니다. 예외는 더미데이터뿐입니다. 아래 경계를 지키면 문제없습니다.

1반입 경계

가져간다 데이터와 머릿속

  • 더미데이터 꾸러미 — 나라장터 공개 공고에서 받은 과업지시서 발췌, 경과원 서식 파일, 입력 예시
  • 기술적 사실 — 어느 API가 무엇을 주는지, 어떤 라이브러리가 있는지. 외워 가거나 당일 다시 찾으면 되는 공개 정보
  • 업무 지식 — 과업지시서에 어떤 항목이 들어가는지, 경과원이 어떤 용역을 발주하는지

안 가져간다 만들어 둔 것 일체

  • 초안생성기 HTML, 과업지시서.py, 그 안의 코드 조각
  • 항목 사전 27개와 기본 문안 — 문서에서 뽑아 정리한 것이라 데이터처럼 보이지만, 이건 설계물입니다. 당일 같은 방법으로 다시 뽑습니다(10분이면 됩니다)
  • 프롬프트 원문을 적어 간 메모

애매하면 안 가져가는 쪽으로. 다시 만드는 데 드는 시간보다 실격이 훨씬 비쌉니다.

2당일 순서

MVP는 둘로 잡습니다. ①이 무너져도 ②만으로 시연이 됩니다.

시간할 일내용
~0:30환경 확인 파이썬·pip·GitHub 접속·나라장터 API 확인. 여기서 막히면 그때 계획을 바꿉니다 — 뒤로 갈수록 바꾸기 어렵습니다.
0:30~1:30MVP ① 근거 수집 나라장터에서 유사 공고를 찾아 첨부 과업지시서를 읽고, 항목별 빈도를 세어 보여 주는 화면. 망이 막히면 더미데이터로 대체.
1:30~2:30MVP ② 초안 생성 항목 사전을 만들고, 입력값과 근거로 문안을 채워 초안을 화면에 띄움.
2:30~3:30한글 문서 출력 pip install python-hwpx → 경과원 서식을 열어 본문만 갈아끼움. 여유가 없으면 건너뜁니다.
3:30~시연 준비 입력 예시로 두세 번 돌려보고, 실패하는 경우를 미리 확인.

3단계별 요령

① 나라장터에서 근거 모으기

  • 공공데이터포털에서 조달청 나라장터 입찰공고정보서비스 활용신청 — 자동 승인, 개발계정 하루 1,000회
  • 용역·물품·공사가 각각 다른 오퍼레이션. 기관명·공고명으로 거르려면 이름이 PPSSrch로 끝나는 쪽을 써야 합니다. 그냥 getBidPblancListInfo…는 필터를 조용히 무시합니다.
  • 조회 기간이 1개월을 넘으면 오류가 납니다. 30일씩 잘라 동시에 던지세요.
  • 첨부파일 이름과 주소가 ntceSpecFileNm1~10, ntceSpecDocUrl1~10에 들어 있고, CORS가 열려 있어 브라우저에서 바로 받아집니다. 서버가 필요 없습니다.
  • 세분류가 3단계로 들어 있습니다. 전시 장치는 72154099, 행사 운영은 「기타사업지원서비스」로 흩어져 있어 세분류만으로는 안 좁혀집니다 — 공고명 유사도를 같이 쓰세요.

② 항목 사전 다시 만들기

가져온 사전을 쓰지 않고 당일 뽑습니다. 방법은 간단합니다.

  • 받은 과업지시서들의 문단 앞머리가 글머리표인 짧은 줄을 모으면 그게 소제목입니다
  • 여러 문서에 공통으로 나오는 소제목을 세면 항목 사전이 됩니다
  • 한 문서의 소제목 하나에 여러 항목이 걸리지 않게, 섹션 하나에 항목 하나만 배정하세요(안 그러면 근거가 엉킵니다)

경과원 행사 용역의 실제 항목은 대략 이렇게 나옵니다 — 행사 개요 / 참가자 모집·관리 / 프로그램 기획·운영 / 장소 선정·공간 조성 / 인력 운영 / 안전·보건 / 홍보·모객 / 홍보물 / 사후관리 / 보고 / 정산. 당일 세어 보면 같은 게 나올 겁니다.

③ 한글 문서 만들기

  • pip install python-hwpx — 한글 프로그램 없이 .hwpx를 읽고 씁니다(Apache-2.0)
  • 새로 그리지 말고 경과원 서식을 열어 본문만 갈아끼웁니다. 글꼴·여백을 지정할 일이 없어집니다
  • 서식의 글머리 체계를 읽어 그대로 따라 쓰세요. 기관마다 다릅니다 — 경과원 단체관은 ❍ (항목명) 내용, 스타트업서밋은 □+-
  • 들여쓰기는 문단 설정이 아니라 글자 앞 공백으로 되어 있습니다
  • 본문을 지울 때 쪽 나눔이 딸려 지워집니다 — 장 머리마다 다시 넣어야 합니다
하지 말 것 — OWPML(한글 XML)을 손으로 쓰는 것. 제가 며칠 썼는데 글꼴 이름 한 글자 때문에 계속 실패했습니다. 라이브러리를 쓰세요. apply_paragraph_format은 정의 없는 문단모양 번호를 만들어 서식을 풀어 버리니 쓰지 마세요.

상황대처

pip 설치 불가 한글 출력은 포기하고 화면 초안 + 텍스트 복사까지만. MVP ①②는 브라우저만으로 됩니다.
한글 프로그램 없음 문제없습니다. python-hwpx는 한글 없이 .hwpx를 만듭니다. 열어볼 수 없을 뿐입니다.
AI 도구로 문안 생성 불가 항목별 기본 문안을 당일 직접 써 넣습니다. 20분이면 됩니다. 「근거 기반」이라는 말은 그때 쓰지 마세요.
시간이 모자람 ③을 버립니다. 항목 빈도표와 화면 초안만으로도 완결된 시연입니다.

6시연 3분

  1. 문제 — 경과원은 분기마다 40여 건의 과업지시서를 새로 씁니다. 비슷한 공고가 이미 나라장터에 있는데 매번 백지에서 시작합니다. (숫자는 7번 참조)
  2. 입력 — 공고명·금액·기간·규모만 넣습니다
  3. 근거 — 같은 유형 공고를 찾아 과업지시서를 읽고, 어느 항목이 몇 건에 나오는지 보여 줍니다. 「우리 기관엔 없는데 다른 기관은 두는 항목」이 핵심입니다
  4. 초안 — 항목별 문안이 채워진 초안, 문장마다 근거 번호
  5. 문서 — 경과원 서식이 입혀진 .hwpx

③이 이 도구의 진짜 값어치입니다. 문장을 대신 써 주는 건 어느 AI나 하지만, 빠뜨린 조항을 짚어 주는 것은 공고를 실제로 읽어야 됩니다.
